# 宣传素材脱敏规则

## 总原则

宣传视频、截图、字幕、旁白、视觉稿、剪辑工程中只能使用演示数据，不使用真实文档、真实地名、真实路径、真实项目名称或真实单位信息。

## 必须替换的内容

| 类型 | 替换规则 | 示例 |
| --- | --- | --- |
| 地名 | 替换为“关键词A”或“某市” | “宁波市” → “关键词A”或“某市” |
| 文件名 | 替换为示例文件名 | “内部材料.pdf” → “示例政策文件-01.pdf” |
| 政策文号 | 替换为模拟编号或直接删除 | “某发〔2025〕12号” → “示例文号〔2025〕01号” |
| 真实路径 | 替换为示例资料库 | `/真实/目录/文件.pdf` → `示例资料库/政策资料/示例政策文件-01.pdf` |
| 真实项目名称 | 替换为“示例项目”“示例资料库”“关键词A” | “内部专项项目” → “示例项目” |
| 正文敏感信息 | 改写为宣传可用模拟正文 | 真实段落 → “……围绕关键词A开展政策梳理……” |
| 单位与人员 | 删除或泛化 | “某单位张三” → “相关单位” |
| 时间节点 | 只保留演示用日期 | 真实会议日期 → “2025-05-20” |

## 禁止出现

- 真实地名。
- 真实文件名。
- 真实目录路径。
- 真实项目名称。
- 政策文号、合同编号、内部编号。
- 单位名称、个人姓名、联系方式。
- 真实文档正文、真实搜索命中段落。
- 本机用户名、本机路径、构建目录、调试日志。

## 推荐使用的演示数据

- 关键词：关键词A。
- 资料库：示例资料库。
- 文件夹：政策资料、规划资料、规范资料、会议资料。
- 文件名：示例政策文件-01.pdf、示例规划文本-2035.docx、示例技术规范-2025.pdf、示例会议纪要-01.docx。
- 正文：“……围绕关键词A开展政策梳理，明确工作目标、实施路径和责任分工……”

## 成片检查清单

- 字幕和旁白统一使用“快文 QuickDocs”。
- 视频中不得出现真实路径或真实文件名。
- 搜索框中只输入“关键词A”。
- 结果列表只展示示例资料库和示例文件。
- 打码画面必须检查逐帧，尤其是弹窗、状态栏、文件名列和设置面板。
